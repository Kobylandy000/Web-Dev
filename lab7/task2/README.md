# Lab 7 - Task 2: OOP in Python

## Description
This project demonstrates Object-Oriented Programming concepts in Python
using an Animal class hierarchy.

## Structure
- `models.py` — Contains Animal, Dog, and Cat classes
- `main.py` — Demonstrates usage of the classes

## How to run
```bash
python main.py
```

## OOP Concepts Demonstrated
- Inheritance (Dog and Cat inherit from Animal)
- Method Overriding (speak() method)
- Polymorphism (calling speak() on different objects)
- Encapsulation (attributes and methods)
